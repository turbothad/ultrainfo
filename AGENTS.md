# ultrainfo

## Agent skills

### Issue tracker

Issues live in Linear — team Tradia ("ultra"), project ultrainfo — via the
Linear MCP server. PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical defaults (`needs-triage`, `needs-info`, `ready-for-agent`,
`ready-for-human`, `wontfix`) as Linear labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
