# TUR-6 — Lean race-facts header

## Objective

Make the race-page opening a compact official-reference surface: identity, course summary, headline stats, registration facts, and one source-verification line.

## Non-goals

- Redesign Course, Aid stations, Crew, Follow, or Sources.
- Change race data, source metadata, or registration state.
- Change routes or map payloads.

## Product requirements

- Keep the existing identity line, race name, one-line course description, and headline stats.
- Remove the editorial race-facts heading and explanatory copy.
- Put registration status and the official registration link in the facts grid.
- Remove the launch-scope card.
- Show `All facts from official race materials · verified <date> · Sources` below the facts grid.
- Derive `<date>` from the latest `verified_on` value in race/source metadata.
- Link `Sources` to `#sources`.

## Technical design

- Keep the HTTP response as the test seam in `RacesControllerTest`.
- Add a small presentation helper that gathers top-level and nested source `verified_on` dates and formats the latest one.
- Compose registration status and its official link inside the existing stat-grid value.
- Keep a quiet fallback if source verification metadata is absent or invalid.

## Likely files

- `app/helpers/application_helper.rb`
- `app/views/races/show.html.erb`
- `test/controllers/races_controller_test.rb`
- `CHANGELOG.md`

## Ordered tasks

1. Add one failing response test covering registration, removed editorial content, and latest-date trust line.
2. Implement the helper and lean facts markup until the focused test passes.
3. Run the controller test, full Rails test suite, and RuboCop.
4. Review the diff against repo standards and TUR-6; address actionable findings.
5. Commit only TUR-6 files with a Conventional Commit message.

## Acceptance criteria

- Registration status and official link appear together in the facts grid.
- The editorial heading, explanatory copy, separate registration card, and launch-scope card are absent.
- The trust line shows the latest verified date and `Sources` links to `#sources`.
- Rails tests and RuboCop pass.

## Verification commands

- `bin/rails test test/controllers/races_controller_test.rb`
- `bin/rails test`
- `bin/rubocop`

## Blocked conditions

- Source metadata lacks any valid `verified_on` value but product requirements disallow a quiet pending fallback.
- Unrelated checkout changes begin overlapping required TUR-6 files.
