# TUR-5 — Single-scroll race page shell

## Objective

Replace the race role-tab interface with one canonical scrolling page organized by information type, while preserving legacy route compatibility through permanent anchor redirects.

## Non-goals

- Redesign section-local content beyond rehoming the current material.
- Change the terrain map JSON payload.
- Add the richer section behavior assigned to TUR-6 through TUR-11.

## Product requirements

- Render, in order: Race facts, Course, Aid stations, Crew & pacers, Follow, Sources.
- Give each section a stable anchor: `facts`, `course`, `aid-stations`, `crew`, `follow`, `sources`.
- Render one terrain canvas and one complete aid-station table.
- Add a slim jump navigation that becomes sticky after the race header scrolls away.
- Permanently redirect runner, crew, follow, and HTML map routes to their canonical anchors.
- Leave `map.json` behavior unchanged.
- Remove tab UI, tab controller, dead role views, role navigation, and global role links.

## Technical design

- Compose the existing content into six semantic sections in `races/show`.
- Keep one map partial invocation in Course and one all-stations table invocation in Aid stations.
- Use normal anchor links plus CSS `scroll-margin-top`; no JavaScript needed for jump navigation.
- Redirect legacy HTML actions with `301 Moved Permanently`; retain the existing JSON branch in `map`.
